Fulltext Bookmark · 全文书签

保存浏览过的网页文字，用记得的内容找回书签和历史记录。

🎇 2.0 来了！
更可靠的网页抓取、更好用的中英文全文搜索，以及全新的侧边栏搜索和加密备份。

🔍 搜索内容，不只搜索标题
按标题、正文或网址搜索已保存的网页，查看匹配摘要和关键词高亮。支持完整短语、中文分词、简繁匹配、英文词形变化、常见缩写和英文拼写模糊匹配，并改善虚词、介词等常见词的处理。

💾 保存你浏览时已加载的文字
自动保存网页文字，并跟进展开正文、滚动加载和异步评论等内容变化。可设置保留时间和排除网址，选择哪些页面需要保存。

📜 三种搜索方式，随你选择
默认在侧边栏中搜索，也可以使用扩展弹窗或独立标签页。在设置中选择点击扩展图标时默认打开哪一种界面。

📎 地址栏快速搜索
在 Chrome 地址栏输入 kw，按 Tab，再输入关键词，即可搜索已保存的内容。

🥇 搜索引擎结果联动
在 Google、Bing 或百度搜索时，显示匹配的已保存页面，方便找回以前看过的内容。

🦉 保存感兴趣的微博
适配新版微博，可保存已展开的长微博及转发正文，之后按内容搜索。

🗂️ 找到并切换已打开的标签页
搜索当前打开的标签页，直接切换过去，减少重复打开。

⌨️ 备份与恢复
支持 JSON、CSV 导出和导入，兼容旧版备份。还可以为备份设置密码，导出加密文件，并在需要时解密恢复。加密仅针对备份文件，不是扩展内数据库加密。

🌏 中英文界面
完整支持简体中文和 English，并改进小屏幕上的布局和操作体验。

😺 本地使用，无需账号
免费使用。网页正文和搜索默认在本机处理，不需要注册账号或使用云端服务。

✉️ 可选自定义 API
如有需要，可主动配置并启用自定义 API，将网页标题、网址等元信息发送到指定地址。此功能默认关闭，并提供测试连接按钮。

已有用户升级
通过原 Chrome 应用商店条目升级，即可继续使用已有数据，无需先导出再导入。

保存范围
扩展保存浏览器已加载的网页文字。导入浏览器原有历史记录只能取得标题、网址等信息；从未保存过的正文，需要再次访问页面后才能补充。

2.0 更新：重构网页抓取与搜索，适配新版微博，新增侧边栏和标签页搜索，支持加密备份，完善中英文界面与小屏幕布局，并修复多项问题。旧版 AskGPT 功能已移除。
